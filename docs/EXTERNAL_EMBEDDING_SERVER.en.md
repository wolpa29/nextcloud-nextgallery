# Set up an external embedding service

[Deutsche Anleitung](EXTERNAL_EMBEDDING_SERVER.md) · [Reference](EMBEDDING_SERVICE_REFERENCE.en.md)

The external service computes image and search-text vectors on a dedicated machine. Nextcloud stores the vectors and performs visual search.

For automatic Gemma installation: Python 3.10+, Docker with Compose, free disk space for container and model. For GPU inference: NVIDIA drivers and NVIDIA Container Toolkit.

## 1. Install the service

Clone the repository and run the installation script (English is default via Enter, German is choice `[2]`):

```bash
git clone https://github.com/wolpa29/nextcloud-nextgallery.git
cd nextcloud-nextgallery
./scripts/install-embedding-server.sh
```

On Windows, run the installer directly with Python:

```powershell
py -3 scripts/install-embedding-server.py
```

The wizard prompts for model (Original, Lite or Custom model), hardware (CPU/GPU), and port (default: `9379`). Configuration and API key are saved in `~/.nextgallery-embedding-server`.

## 2. Check readiness

Once the container is running and the model has loaded, verify functionality using synthetic test requests:

```bash
python3 scripts/install-embedding-server.py --action check
```

If the model is still loading, [view its progress](EMBEDDING_SERVICE_REFERENCE.en.md#troubleshooting) and repeat the check later.

## 3. Connect in NextGallery

Open **NextGallery → Settings → Visual image search · Embeddings**:

| Setting | Value |
| --- | --- |
| Embedding service | External embedding server |
| Model family | EmbeddingGemma 2, Qwen3-VL-Embedding or Custom model |
| Model ID | Exact ID reported by the service (e.g. `embeddinggemma-2-full` or `embeddinggemma-2`) |
| API address | `http://SERVER-IP:9379/v1` (or HTTPS address) |
| API key | Key generated by the installer |

1. Click **Check connection** before saving.
2. Pause ongoing embedding jobs under **User runs** and let the current file finish.
3. Enable **Enable for users** and save. Compatible vectors are kept; a different vector space requires confirmation to rebuild.

## Custom models

Choose **Custom model** in the wizard and **Model family → Custom model** in NextGallery. Install your chosen model using its own runtime. The service must embed both image and text requests into the same vector space.

For adapters, API details and troubleshooting, see the [technical reference](EMBEDDING_SERVICE_REFERENCE.en.md).
